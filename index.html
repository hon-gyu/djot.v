djot.v

A djot parser written and verified in Rocq, and extracted to OCaml.

djot was designed around a few goals: parsing never backtracks, text means the same thing inside a container as outside it, a link is recognized without looking at the rest of the document, and a paragraph can be hard-wrapped anywhere. Here those goals are theorems about the parser.

djot is one setting of the parser. Its inline delimiters can be respelled, its constructs can be switched off, and extensions can be switched on. For each setting, the proofs say which of the properties it keeps. A Markdown-like profile, for example, keeps no backtracking and uniformity, and gives up safe hard-wrapping.

  • Playground: run the parser in the browser, change the profile, and see which properties the profile keeps.
  • Extensions: the syntax of each extension.
  • API: the extracted parser as an OCaml library, and as a Python package.

Properties

The status of each property under the two named profiles. The playground shows the same for any profile.

proved
The theorems hold for the profile.
conditional
They hold under a condition on the document, stated below the status.
broken
The property fails for the profile, for the reason stated.
conjectured
Believed to hold, and not proved for the profile.
unknown
No claim either way.
inapplicable
The property is about a construct that is switched off.
