val to_string : ?profile:Profile.t -> ?style:style -> t node list -> string

The inlines as djot source, as they are written inside a paragraph, a soft or hard break ending a line.

  • parameter profile

    the syntax to write; default Profile.djot

  • parameter style

    default `Checked, which reads the inlines as one paragraph
