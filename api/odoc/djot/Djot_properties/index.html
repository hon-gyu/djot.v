Module Djot_properties

The properties proved of the parser, and which of them a profile keeps.

The list is Djot.Kernel.Properties, extracted from theories/Properties.v. There each property has, beside the words given here, its statement for a profile and a proof of that statement wherever status is Proved or Conditional.

type status = Djot.Kernel.Properties.status =
  1. | Proved
    (*

    The theorems hold for the profile.

    *)
  2. | Conditional of string
    (*

    They hold, under the stated condition on the document.

    *)
  3. | Broken of string * string
    (*

    Broken (reason, example): the property fails for the profile; example is a source that shows it.

    *)
  4. | Conjectured
    (*

    Believed to hold; not proved for this profile.

    *)
  5. | Unknown
    (*

    No claim.

    *)
  6. | Inapplicable of string
    (*

    The construct the property is about is off.

    *)
val status_name : status -> string

The constructor's name in lower case: "proved", "conditional".

type t
val id : t -> string

A stable name, e.g. "hard-wrap-paragraph".

val group : t -> string

The design goal the property belongs to, e.g. "Safe hard-wrapping".

val statement : t -> string
val implication : t -> string

What the property gives a writer or a tool.

val theorems : t -> string list

The names of the theorems in the Rocq development.

val status : t -> Djot.Profile.t -> status
val all : t list

Every property, grouped as group names them.
