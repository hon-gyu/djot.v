# Proposal: finish the measured inline long-line paths

## Problem

Buffered inline source no longer copies its prefix on each byte, but
several consumers still copy native string tails at close.  In addition,
the attribute token and label-word builders copy their growing prefixes.
The affected shapes and the remaining delimiter-search cost are recorded
in `extracted-performance.md`.

## Design

1. Give `source_shape` and `wiki_split` narrowly scoped linear native
   realizations while retaining their Gallina definitions for proofs.
   Differentially check both realizations, including newline and escaped
   bar cases.  Autolink's close-time body, kind, and email predicates
   have the same tail-copy problem, so give those focused linear native
   realizations too.  The escaped-whitespace close also reads the last
   byte of a completed run, so realize `str_last` in constant time.
   Avoid a global string representation change.
2. Build attribute tokens as reversed character lists, converting only
   when committed.  Prove the existing identifier roundtrip lemma for the
   new representation.  Build label words in reverse as well; preserve
   `words` and `normalize_label` extensionally.
3. Replace repeated delimiter-table search with a direct character
   dispatch, prove equality to `dstyle_at` under the admitted profile
   conditions, and use it in the scanner.  Retain the table definition as
   the specification.
4. Recheck `isnoc` and `osnoc` with a realistic seam-heavy input.  Change
   their representation only if repeated large merges are observed; their
   current small-seam benchmark does not justify a broad AST rewrite.

## Checkpoints

Compile the changed proof files without admits or new axioms.  Compare
the old and new extracted parsers for semantic and located results, run
the repository checks and standalone distribution tests, and time the
affected long constructs plus ordinary text and delimiter-heavy input.
Record results and any remaining bottleneck before committing.

## Result

The extracted close-time helpers scan by offset.  Attribute tokens and
label words grow as reversed byte lists, with a native linear conversion
at commit; `words_spec` relates the new word builder to its prior Gallina
definition, and the identifier roundtrip proof was updated for the new
attribute state.  `dstyle_at_fast_eq` proves that the direct row dispatch
is definitionally equal to the table lookup.  The default Djot profile
disables wikilinks, so the wikilink benchmark now enables that capability.

The old and new extractions matched on semantic and located output,
plus direct helper checks, in 2,268,150 focused comparisons.  A planted
mismatch was detected.  Repeated escaped punctuation at 4/16/64 KB took
0.11/0.50/2.19 ms before and 0.12/0.53/2.60 ms after; the seam merges
do not show a long-line growth problem on that input, so their flat AST
representation was retained.  Long plain words and long wikilink targets
still pay structural scans in the block parser after the inline scan;
they need a separate line-level change.
