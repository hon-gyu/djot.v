# agent answers for the first two questions
1. Why wasn't it caught earlier?

The corpus does not contain the shape. Across 26 test files there are exactly 3 marker-line nested lists (- - - a, - - - - -, - - -), and zero of them are followed by an indented sibling. That's the only shape that triggers the bug.

The reason is specific: open_list recorded the wrong column only when a list was opened from a marker residue. A normally-nested list (- a /   - b) opens from the padded line itself, where indent_of was already the absolute column — correct even before the fix. And - - - a on one line has no continuation, so the wrong indents never get compared against anything. You need both halves — nested on the marker line and a following sibling — and the corpus has one without the other.

So this isn't a case of the signal being drowned out by our 212 mismatches. The case simply isn't there. I found it by construction, not by testing: stating the shift theorem forced me to ask what open_list records on each path, and one path answered wrong.

2. Is corpus conformance not enough?

Not for this class of bug, for two independent reasons.

Coverage: the corpus is djot.js's regression suite, so it covers what djot.js's authors got wrong or thought worth pinning. It's not a systematic exploration of the block grammar. Nothing forces it to contain the product of "nesting position" × "has continuation".

Granularity: even a corpus case that did cover it would be invisible today. We compare final HTML; with inline parsing unstarted, 212 of 287 cases already mismatch. A block-structure regression cannot be distinguished from the inline noise. The Phase 2 plan anticipated exactly this — its exit criterion says "inline content compared as raw text at this stage" — but the harness has no such mode yet. That's a real gap and it's cheap to close: project both sides' trees to block shape with inlines flattened to text, and compare. That would turn 212 mismatches into a number that means something, and would have made this bug visible the moment a covering case existed.
