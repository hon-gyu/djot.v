# The renamed site's canonicity, and why the general statement is not one theorem

`260902.document-model.md` left one obligation: *a renamed site is still
canonical*, priced as "the codec spells `no_nl` / `no_ws` destinations
and a fact about what a destination can do to a rendered line". Both
halves of that price were wrong in the same direction. The two codec
conditions are necessary and nowhere near sufficient, and the "fact
about a rendered line" is not a fact but the whole of `classify`.

## What was landed

`Site.v` gains the identity half of `cb_dests_map` -- `ci_map_dest_id`
through `doc_map_dest_id`, one per layer -- and on top of it:

- `retarget_id`: re-targeting a note that stays put, by a substitution
  that fixes every note it points at, rewrites nothing. It is
  `l_spell_canonical` doing the work: a destination that parses is
  already spelled the way the codec spells it, so the re-spelling
  branch returns its own input.
- `touched_entry`: decidable, and it is `backlinks`' membership test
  with the renamed note itself added.
- `rename_entry_untouched`: an untouched note is carried across *as the
  same value*, not merely as an equivalent one.
- `rename_canonical_local`: the canonicity check after a rename need
  only run on the touched entries. Everything else is the entry the
  build already checked.

That is the useful half of the obligation. A rename over a vault of
5000 notes runs `cblocks_ok` on the backlink set, and the theorem says
the rest is unchanged rather than "probably fine".

## Why the other half is not one theorem

`cb_ok` reads the *rendered line*, and a destination is a field of the
AST, so a substitution moves the line. The predicted conditions do not
control that.

- `dest_ws_breaks_ref` is the predicted one and is real: `[r]: a b`
  splits at the space.
- `dest_bar_breaks_row` is a `no_ws` destination that leaves a table
  uncanonical: `| [a](a|b) |` has two cells. A bar is not escaped by
  `escape_dest`, because the inline layer has no reason to escape it.
- `dest_backtick_breaks_row` is the same and sharper, because
  `escape_dest` *does* escape a backtick and the escape does not help.

Both table cases are fine in a paragraph. So the boundary is not a
property of destinations at all: the same destination is admissible or
not depending on which block encloses it.

The backtick case turned out to be a bug on our side rather than a
boundary -- `Line.row_cells` counts verbatim runs without honouring a
backslash, so we read `| a\`b |` as text where djot.js reads a row. It
is logged in `oracle-disagreements.md` under *2026-09-03*, with the
control (`| a`b |`, where both engines say text) that makes it narrow.
It was found by asking what a rename may write, not by the corpus: no
generated document puts a backtick in a table cell, so `make generated`
is 5438/5438 while the shape is unreachable.

## What the general theorem would actually cost

The obligation, stated properly: for a substitution whose values are
line-safe, every arm of `cb_ok` is preserved. Its arms are

| arm | what a destination can move |
| --- | --- |
| `CRef` | `ref_ok`: `no_ws` and nothing else -- cheap, `ref_ok_classify` exists |
| `CPara`, `CHeading` | `classify` of each rendered line, `bcuts`, trailing whitespace |
| `CQuote`, `CDiv`, `CList` | the inner blocks' lines, through `cb_pairs_ok`, `div_content_ok`, `item_ok` |
| `CTable` | `ctrow_ok`, which is a re-scan of the row |

The paragraph arm is the one that decides the price, and it is not a
lemma. It needs `classify (u ++ v) = classify (u ++ w)` where `u` is
the unchanged prefix up to the link's `](`. Eleven openers have to be
shown insensitive to the change. Seven of them decide inside `u`,
because `](` terminates every prefix scan. `is_thematic` is false
because `u` holds a non-marker character. `foot_open` and `ref_open`
find their first unescaped `]` at or before the `](`, so their answer
is fixed by `u`. `table_row` is decided by the line's first and last
characters, and the last character is the link's `)`. None of that is
deep; all of it is string reasoning that does not exist yet, and it has
to be lifted through `ci_text`, `cb_lines` and `sep_lines` afterwards.

**Price, in the form the lessons file asks for**: no statement in
`Render.v` or `Line.v` acquires a hypothesis, and no existing predicate
splits -- the work is new lemmas, not migration. That is what makes it
schedulable rather than urgent, and it is why the reduction above was
landed on its own ([[project-engineering-lessons#Split a fix by proof
cost before landing it, and look for the cheap spelling]]).

**Order.** The `row_cells` escape bug comes first: it changes which
lines are rows, so any invariance lemma proved about `table_row` before
it would have to be re-proved after.
