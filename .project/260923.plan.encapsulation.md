## 1. Facts this plan rests on

Recorded against Rocq 9.1.1. Dune must support the project's declared
language version 3.22. These are migration constraints, not substitutes
for compiling the result.

1. **A `Module` cannot be opened inside a `Section`.** To put a cluster
   that sits inside `Section WithTable` into a module, the section is
   closed, the module opened, the section reopened inside it with the same
   `Context` lines, and the same again after the module. The tool does
   this.
2. **`Local` hides the short name only.** `Local Definition f` in file A
   is invisible as `f` in another file but still reachable as `A.f`.
   Extraction ignores `Local`, so B does not change the OCaml API. This is
   imported-name hygiene, not an enforceable abstraction boundary.
3. **Modules compute.** An unsealed module changes nothing for
   `reflexivity`, `vm_compute` or `cbn [Attr.set]`. Never seal a module
   with a signature (`Module M : SIG`): sealed definitions stop
   computing, and this development relies on computation.
4. **Extraction turns a module into an OCaml submodule.** A name moved
   into `Module Attr` in `Ast.v` becomes `Djot.Ast.Attr.set` in OCaml. The tool conservatively refuses names used by known OCaml consumers
   ("frozen names"). This is a tool limitation, not a reversal of §0's
   permission to migrate the API. A conflicting planned wave needs an explicit
   consumer-update recipe under R2; do not silently drop its members.
5. **Use unique short module names in this migration.** When two imported
   files each define a module `E` and both have a member `x`, `E.x`
   silently resolves to the later import. Nothing warns.
6. **A short name inside a module shadows a global of the same name**
   for the rest of the module. `Definition inline` inside `Module Erase`
   makes the type `inline` unreachable there. The tool rejects any new
   name that already occurs in the range, and a list of reserved names.
7. **Leaving a section changes how `@name` must be written.** Inside
   `Section WithTable`, a name declared in the same section is written
   `@name a b`. From outside the section, including a reopened copy of
   it, the section variables come first: `@name T a b`. `About name`
   reports them (`Arguments dchar {T} k`). The tool asks Rocq and inserts
   them.
8. **A section-local `Ltac` is lost when the section closes.** The tools
   copy it into every reopened section that needs it. They refuse when
   the tactic writes `@name` for a name of the same section.
9. **`destruct` on a record names the new hypotheses after the record's
   fields.** When the record lives in another file, a hypothesis
   `fr_kind` shadows the projection `fr_kind`, and a later `cbn
   [fr_kind]` fails with "Cannot coerce fr_kind to an evaluable
   reference". This happens exactly once in A (§3, step A4).
10. **`expect-test/` is a consumer.** `expect-test/MarkdownLike.v` is
    built by dune and uses public names (`parse_profile_doc`), and
    `dune test` diffs its output. The census scans it.
