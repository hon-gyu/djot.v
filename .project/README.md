- We store project relevant context in this directory.
- If something can drift across development loops, we attach date or / and commit hash to it.
- Undated files are the exception: they are meant to persist and be
  amended in place rather than superseded.
  - `project-engineering-lessons.md` — how to decide, not how to code.
    Read before committing to a direction.
  - `oracle-disagreements.md` — append-only adjudication log.
  - `baseline-report.txt` — regenerated by `make baseline`.
