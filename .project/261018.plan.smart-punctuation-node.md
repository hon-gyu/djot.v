# Plan: a node for smart punctuation

## Goal

An inline constructor for a piece of smart punctuation, holding what
was typed and what it renders as.  Then `alt` and a derived id read what
was typed, as decided on 2026-10-04 (`json-gaps.md`, "Smart
punctuation: the plan"):

| input | djot.js | ours today | ours after |
| --- | --- | --- | --- |
| `# What's new` | `id="What's-new"` | `id="What’s-new"` | as djot.js |
| `# a--b` | `id="a--b"` | `id="a–b"` | as djot.js |
| `![it's](u)` | `alt="it's"` | `alt="it’s"` | as djot.js |

Started before the punctuation map, against that plan's ordering
(maintainer, 2026-10-18).  The map would change the eight scanner sites
again; the traversals and the proofs, which are most of the work, it
would not.

## Decisions

- **The constructor.** `SmartPunctuation (src s : string)`: `src` is the token as
  djot.js records it, `s` its rendering.  A tree rendered with no
  document has no map to look in, so the node carries both.
- **One node per token**, as djot.js makes them: an unmatched quote, an
  ellipsis, an en dash, an em dash.  `----` is two en-dash nodes.  A run
  of periods past a multiple of three leaves its rest as text (`.....` is
  an ellipsis and `..`).
- **What `src` holds.** The bare token: `{'` and `'}` both record `'`,
  as djot.js does.  A dash records `--` or `---`, an ellipsis `...`.
- **When there is no node.** With smart typography off, dashes and
  periods are text as now.  A row whose decay is `DDSelf` leaves text.
  A lone hyphen is text.
- **What reads which.** HTML writes `s`.  `Document.inline_text` (alt,
  derived ids, `inlines_text`) reads `src`.  The djot writer writes
  `src`, with a marker where the side would otherwise change (`{'` for a
  left single quote, `"}` for a right double one); the canonical view
  gets no case, so the round trip theorem is unchanged and says nothing
  about these nodes.
- **Attachment.** A spec after text attaches to the whole last word
  (2026-10-18, `djotjs-divergences.md`), and a word runs across these
  nodes.  A word that is one node takes the attributes itself, as a `Str`
  does now; a word of several (`a'{.a}` is `Str "a"` and a quote) is
  wrapped in an unnamed `Span` that takes them.  The HTML is unchanged:
  `<span class="a">a’</span>`.  `Html` writes the attributes of a `SmartPunctuation`
  node with a span, as it does for a `Str`, where djot.js drops them.
